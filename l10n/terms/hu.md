# Scout in Hungarian (hu): term list

Machine translation, no native reviewer yet. Formal address (Ön, third-person imperative: Válasszon, Adja meg, Kapcsolja be) as the Hungarian App Store text does. Menu items and buttons are verbal nouns the way macOS writes them (Megnyitás, Bezárás, Mentés); a few notch buttons use the short imperative (Engedélyez, Elutasít, Módosít, Mutat) to stay near the English length. Words match the App Store text, except Tray (see below).

Hungarian adds suffixes to words, so brand names are never declined: "a Scout app", "a Codex programban", "a Mac Keychain tárolójában"; placeholders get no suffix ("%@ itt: %@", "ide: %@").

Pixel labels use capitals and no accents (the 5x7 font has none): EGESZ NAP, ALSZIK, VISZLAT %@ (BYE), KAPCSOLODAS, KESZ, GYORS KERDES AI, KEDVENCEK, ALLOKEP, SCOUT UDVOZOL, LEGUTOBBI, LISTA, ONRE VAR, NINCS UGYNOK, NINCS JEL, SZUNETEL, HELYEK, KESZEN ALL, INDUL, LEALLITVA, UDV %@, FOLYAMAT, DOLGOZIK.

Style: „ ” quotes, "…" as one character, no dashes as separators (a colon instead: "Fókusz: %@"), Western digits.

Choices made while translating:
- Left/right for AirPods: B / J (bal / jobb). Case = Tok.
- "Ask anything" (the Ask AI field placeholder, 12 characters at most) = "Kérdezzen" (9).
- "A(z) %@" is used where the article depends on the unknown word that fills %@.
- "Needs you" = "Szüksége van Önre"; the pixel label is "ONRE VAR" (waits for you) because it is short.
