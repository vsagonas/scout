Machine translation, no native reviewer yet. macOS has no Lithuanian interface, so there is no Apple wording to copy: the words below are the plain, common ones of Lithuanian software (Microsoft, Android, everyday tech speech).
Buttons and menu items are infinitives, as Lithuanian software writes them (Atidaryti, Uždaryti, Išsaugoti, Pridėti). Sentences speak to the user informally ("tu": Pridėk, Pasirink, tavo Mac). Quotation marks „ “. No counted plural forms: "Agentai: 3", "Atidaryta: 3", "dar 3".

Apple app and Settings names: macOS shows them in English on a Lithuanian user's Mac (there is no Lithuanian macOS), so where a sentence sends the user to a macOS pane or app, the exact English name is kept: Privacy & Security, Full Disk Access, Screen Recording, Automation, Paste from Other Apps, Login Items, Contacts, Calendars, Notes, Messages, Music, Shortcuts, Activity Monitor, Weather.
Scout's own tab and setting names are translated and used the same everywhere (Nustatymai › Klausti DI).
Finder, Spotlight, Keychain stay as they are.

Pixel-font keys (l10n/PIXEL-LABELS.txt): capitals, A-Z only, no diacritics: ALL DAY = VISA DIENA, ASLEEP = MIEGA, BYE = IKI, DONE = ATLIKTA, READY = PARUOSTA, NEEDS YOU = REIKIA TAVES, NO AGENTS = NERA AGENTU, FROZEN = UZSALDYTA, RADIO = RADIJAS, HELLO FROM SCOUT = LABAS NUO SCOUT.
Short widget titles prefer a word without diacritics where one exists (Radijas, Pulsas, Veidrodis, Medija, Orai); where the natural word has one the pixel font draws it without the marks, which stays readable.
Brand names stay Latin: Scout, Claude, Claude Code, Codex, OpenAI, GPT, Anthropic, Mac, macOS, AirPods, AirDrop, Spotlight, Keychain, Zoom, Meet, Teams, Webex, Spotify. Digits 0-9. No dashes as separators (a colon or comma instead).
