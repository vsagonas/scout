Machine translation, no native reviewer yet. macOS has no Estonian interface, so there is no Apple wording to copy: the words below are the plain, common ones of Estonian software (Microsoft, Android, everyday tech speech).
Informal singular imperative for buttons and menu items (Ava, Sule, Salvesta, Lisa), as Estonian apps write them. Quotation marks „ “. No counted plural forms: "Agendid: 3", "Avatud: 3", "veel 3".

Apple app and Settings names: macOS shows them in English on an Estonian user's Mac (there is no Estonian macOS), so where a sentence sends the user to a macOS pane or app, the exact English name is kept: Privacy & Security, Full Disk Access, Screen Recording, Automation, Paste from Other Apps, Login Items, Contacts, Calendars, Notes, Messages, Music, Shortcuts, Activity Monitor, Weather.
Scout's own tab and setting names are translated and used the same everywhere (Seaded › Küsi TI-lt).
Finder, Spotlight, Keychain stay as they are.

Pixel-font keys (l10n/PIXEL-LABELS.txt): capitals, A-Z only. õ ä ö ü are written o a o u: ALL DAY = KOGU PAEV, ASLEEP = MAGAB, BYE = NAGEMIST, DONE = VALMIS, READY = VALMIS, NEEDS YOU = VAJAB SIND, NO AGENTS = AGENTE POLE, HELLO FROM SCOUT = TERE SCOUTILT.
Short widget titles prefer a word without diacritics where one exists (Ilm, Kalender, Taimerid, Aku, Meedia, Peegel, Salv); where the natural word has one (Märkmed, Ülesanded, Täna, Lõikelaud) it is kept and the pixel font draws it without the dots, which stays readable.
Brand names stay Latin: Scout, Claude, Claude Code, Codex, OpenAI, GPT, Anthropic, Mac, macOS, AirPods, AirDrop, Spotlight, Keychain, Zoom, Meet, Teams, Webex, Spotify. Digits 0-9. No dashes as separators (a colon or comma instead).
