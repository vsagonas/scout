# Maltese (mt): term list

Machine translation, no native reviewer yet: together with Irish the weakest of the seven. Maltese is not a macOS interface language, and Maltese speakers mostly use their Mac in English, so the plainest standard terms (Maltese software wording as far as I know it) are used, and widely used English technical words are kept (widget, notch, dashboard, chat, clipboard, tab, hooks, shell, Prompter, Nook, Pocket, AI, Mute, Play).
Buttons and menu items are the informal singular imperative (Iftaħ, Agħlaq, Salva, Żid); sentences speak to the user informally (inti, -ek). Quotation marks “ ” (as in the English). No counted plural forms: "Aġenti: 3", "Miftuħ: 3", "3 oħra". Sentences are kept short and simple on purpose.

Apple app and Settings names: macOS shows them in English (there is no Maltese macOS), so where a sentence sends the user to a macOS pane or app, the exact English name is kept: Privacy & Security, Full Disk Access, Screen Recording, Automation, Paste from Other Apps, Login Items, Contacts, Calendars, Notes, Messages, Music, Shortcuts, Activity Monitor, Weather.
Scout's own tab and setting names are translated and used the same everywhere (Issettjar › Staqsi lill-AI).
Finder, Spotlight, Keychain stay as they are.

Pixel-font keys (l10n/PIXEL-LABELS.txt): capitals, A-Z only, no diacritics (ċ ġ ħ ż become C G H Z): ALL DAY = JUM KOLLU, ASLEEP = RIEQED, BYE = CAW, DONE = LEST, READY = PRONTU, NEEDS YOU = GHANDU BZONNEK, NO AGENTS = L-EBDA AGENT, NO SIGNAL = L-EBDA SINJAL, HELLO FROM SCOUT = BONGU MINN SCOUT, WELCOME = MERHBA.
Short widget titles prefer a word without diacritics where one exists (Polz, Mera, Radju, Kompiti); where the natural word has one the pixel font draws it without the mark, which stays readable.
Brand names stay Latin: Scout, Claude, Claude Code, Codex, OpenAI, GPT, Anthropic, Mac, macOS, AirPods, AirDrop, Spotlight, Keychain, Zoom, Meet, Teams, Webex, Spotify. Digits 0-9. No dashes as separators (a colon or comma instead).
