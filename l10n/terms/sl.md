Machine translation, no native reviewer yet. macOS has no Slovenian interface, so there is no Apple wording to copy: the words below are the plain, common ones of Slovenian software (Microsoft, Android, everyday tech speech).
Informal singular imperative for buttons, menu items and sentences (Odpri, Zapri, Shrani, Dodaj, tvoj Mac), as Slovenian apps write them. Quotation marks „ “. No counted plural forms (Slovenian has a dual): "Agenti: 3", "Odprto: 3", "še 3".

Apple app and Settings names: macOS shows them in English on a Slovenian user's Mac (there is no Slovenian macOS), so where a sentence sends the user to a macOS pane or app, the exact English name is kept: Privacy & Security, Full Disk Access, Screen Recording, Automation, Paste from Other Apps, Login Items, Contacts, Calendars, Notes, Messages, Music, Shortcuts, Activity Monitor, Weather.
Scout's own tab and setting names are translated and used the same everywhere (Nastavitve › Vprašaj UI).
Finder, Spotlight, Keychain stay as they are.

Pixel-font keys (l10n/PIXEL-LABELS.txt): capitals, A-Z only, no diacritics (č š ž become C S Z): ALL DAY = CEL DAN, ASLEEP = SPI, BYE = ADIJO, DONE = KONCANO, READY = PRIPRAVLJEN, NEEDS YOU = POTREBUJE TE, NO AGENTS = NI AGENTOV, NO SIGNAL = NI SIGNALA, HELLO FROM SCOUT = POZDRAV IZ SCOUT.
Short widget titles prefer a word without diacritics where one exists (Radio, Pulz, Ogledalo, Vreme, Mediji, Opravila); where the natural word has one the pixel font draws it without the marks, which stays readable.
Brand names stay Latin: Scout, Claude, Claude Code, Codex, OpenAI, GPT, Anthropic, Mac, macOS, AirPods, AirDrop, Spotlight, Keychain, Zoom, Meet, Teams, Webex, Spotify. Digits 0-9. No dashes as separators (a colon or comma instead).
